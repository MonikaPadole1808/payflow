# Important Architectural Decisions

## Automatic Wallet Provisioning

A wallet is automatically created immediately after successful user registration.

Flow:

Register User
↓

Persist User
↓

Provision Wallet
↓

Return Success Response

Authentication depends only on `WalletProvisioningService`, not on `WalletRepository`, preserving module boundaries.

---

## Monetary Representation

All monetary values use `BigDecimal`.

Floating-point types (`double`, `float`) are prohibited.

---

## Wallet Ownership

Business Rule:

- One User → One Wallet

Enforced by:

- Database unique constraint
- Service validation

---
